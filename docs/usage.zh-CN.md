# AXE GOKZ 资源安装工具

**工具本身无需安装。下载一个 EXE 文件，直接运行即可。**

适用于 Windows 10/11 上的独立版 CS:GO Legacy（Steam 应用 4465480）。
不支持 CS2（应用 730）或其中的旧测试分支。

1. 下载并打开 `AXE-Resource-Installer.exe`。
2. 确认自动检测的游戏文件夹，点击 **安装资源**。
3. 等待显示 **资源安装完成**。如果游戏已在运行，请重新连接服务器以加载新资源。

程序会自动使用 Windows 的语言，也可以在同一页面右上角切换语言。
如果发现多个安装位置，请选择需要的一个；如果未能找到游戏，请点击
**浏览**，选择 Steam 安装的独立版游戏文件夹或其中的 `csgo` 文件夹。

无需安装 7-Zip、Python 或额外运行库。程序包含解压工具，并使用
Windows 自带的 PowerShell 5.1，不会打开命令行窗口。工具不创建快捷方式、
后台服务或卸载项目。

程序从以下地址下载当前资源包：

<https://r2.axekz.com/packages/ResourcesPack.7z>

资源需要更新时，再次运行同一个 EXE 即可。已有的同名资源会被替换，
无关文件及个人配置会保留。下载可以取消或重试；开始安装后，请等待完成，
不要强行结束程序。

安装时可以保持 CS:GO 运行。只有资源文件被锁定、无法替换时，才需要关闭
占用该文件的程序后重试。仅在确有权限问题时，右键程序选择
**以管理员身份运行**。程序不会自动关闭您的游戏。

诊断日志位于 `%LOCALAPPDATA%\AXE\ResourceInstaller\logs`。
正常退出会清理当前下载及解压临时文件。如果自动恢复失败，请保留日志中
注明的 `.axe-resource-backup-*` 备份文件夹，并联系 AXE GOKZ 管理员。

当前 EXE 尚未进行代码签名，Windows 可能根据安全策略显示未知发布者提示。
此工具只安装游戏资源，不修改 Steam 启动信息，也不会自动启动游戏。
